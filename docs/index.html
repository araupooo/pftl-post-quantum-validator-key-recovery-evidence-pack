PFTL Post-Quantum Validator Key Recovery — Results

Live testnet (network 2025, postfiatd 1.0.9), probed 2026-11-22 20:14 UTC. Validated ledger seq 8,279,102. Pinned postfiatd commit 0085a1ff885d6a446369cf73a4430f75af22be55.

Verdict: NOT READY — ephemeral-key recovery works by design; master-key recovery does not exist; no quantum-resistant path. Rotating a lost or compromised ephemeral signing key is a solved problem (new manifest, sequence + 1, propagates in minutes) and the drill recovers it in 0.1 s of lab time. Losing the master key is unrecoverable by design: no new manifest can be signed and the only path is a brand-new validator identity. The documented backup is a single file (validator-keys.json) that is deleted on container restart, with no threshold scheme anywhere in the code or docs. The whitepaper promises ML-DSA-65 validator signatures from genesis; the pinned code has none, every live validator key is classical, and an ML-DSA-65 signature (3,309 bytes) cannot fit the 512-byte manifest cap.
